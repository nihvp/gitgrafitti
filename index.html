Do you already know the basics of Git and GitHub?

Beginner's Guide

No problem! Follow these steps to get your art on your profile.

  1. Go to GitHub and create a new repository. Name it git-art. Do NOT check "Add a README".
  2. If you are on Windows, download and install Git Bash. Mac/Linux users can use the default Terminal app.
  3. Open your terminal and type mkdir git-art to create a folder, then cd git-art to enter it.
  4. Type git init and press Enter.
  5. Use this website to draw your art and click Generate. Copy the code.
  6. Paste the code into your terminal and press Enter. Wait for it to process.
  7. Go back to your empty GitHub repository page, copy the command that looks like:
    git remote add origin https://github.com/YOUR_USERNAME/git-art.git
    Paste it in the terminal and hit Enter.
  8. Finally, type git push -u origin main (or master) and hit Enter!
